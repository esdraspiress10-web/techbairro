# Manual de uso da TechBairro

## A tela principal

A tela principal apresenta quatro campos para preencher os dados do cliente:

- **Nome:** nome completo do cliente.
- **Telefone:** telefone para contato.
- **E-mail:** endereço de e-mail do cliente.
- **Endereço:** endereço residencial do cliente.

A tela também possui os botões **Salvar cliente** e **Consultar clientes**.

## Cadastrar um cliente

1. Abra a TechBairro.
2. Preencha o campo Nome.
3. Informe o Telefone.
4. Preencha o E-mail.
5. Informe o Endereço.
6. Clique em **Salvar cliente**.
7. Confira a mensagem apresentada pelo sistema para verificar se o cadastro foi realizado.

## Consultar os clientes cadastrados

1. Abra a TechBairro.
2. Clique em **Consultar clientes**.
3. Consulte a lista ou janela apresentada com os clientes cadastrados.

## Alterar os dados de um cliente

1. Consulte os clientes cadastrados.
2. Localize o cliente que precisa de alteração.
3. Selecione o cliente, caso essa opção esteja disponível.
4. Altere os dados necessários.
5. Confirme a alteração conforme as opções apresentadas pelo sistema.

## Excluir um cliente

1. Consulte os clientes cadastrados.
2. Localize e selecione o cliente desejado.
3. Utilize a opção de exclusão, caso esteja disponível.
4. Confirme a operação, se o sistema solicitar.

## Regras de preenchimento

| Campo | Obrigatório? | Regra |
|---|---|---|
| Nome | A confirmar | Informe o nome do cliente. |
| Telefone | A confirmar | Informe um telefone válido para contato. |
| E-mail | A confirmar | Informe um e-mail válido. |
| Endereço | A confirmar | Informe o endereço do cliente. |

## Mensagens do sistema

As mensagens abaixo devem ser preenchidas após testar o programa e conferir os textos que aparecem na tela.

| Mensagem | O que significa | O que fazer |
|---|---|---|
| A confirmar | Cadastro realizado com sucesso. | Verifique se os dados foram salvos. |
| A confirmar | Campo obrigatório não preenchido. | Preencha o campo solicitado. |
| A confirmar | Nome inválido. | Confira o nome informado. |
| A confirmar | Telefone inválido. | Confira o telefone informado. |
| A confirmar | E-mail inválido. | Confira o e-mail informado. |
| A confirmar | Cliente não encontrado ou operação não realizada. | Confira os dados e tente novamente. |

## Dúvidas frequentes

**Como cadastrar um cliente?**

Preencha os campos solicitados e clique em **Salvar cliente**.

**Como consultar os clientes cadastrados?**

Clique em **Consultar clientes**.

**O que fazer se o cadastro não funcionar?**

Confira se os dados foram preenchidos corretamente e observe a mensagem apresentada pelo sistema.
